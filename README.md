# 🧩 Codeblocks

Мобильное приложение для визуального программирования. Позволяет пользователям создавать алгоритмы, собирая их из логических блоков, и запускать их во встроенном интерпретаторе.
## ✨ Основные возможности

+ Визуальный редактор: Интуитивный интерфейс Drag-and-Drop для управления блоками кода.

+ Собственный интерпретатор: Выполнение программ в реальном времени прямо на мобильном устройстве.

+ Разнообразие блоков: Поддержка переменных, циклов (for, while), условий (if-else) и математических операций.

+ Консоль вывода: Просмотр результатов работы программы и отладка в специальном окне.

## 🛠 Технологический стек
+ Framework: React Native Expo.

+ State Management: (Например, Redux Toolkit или Zustand) — для управления деревом блоков.

+ Logic: Custom AST-based interpreter (или укажи библиотеку, если использовал, например, Blockly).

+ Styling: Styled Components / Tailwind CSS (подставь своё).

## 🧠 Как это работает

### Проект разделен на три основных этапа:

+ UI Layer: Пользователь манипулирует компонентами-блоками.

+ Parser: Приложение обходит дерево визуальных блоков и генерирует промежуточное представление (Abstract Syntax Tree).

+ Execution Engine: Интерпретатор пошагово выполняет инструкции AST, взаимодействуя с выделенной областью памяти приложения.

## 🚀 Быстрый старт
### Требования

+ Node.js (> 16.x)

+ Android Studio / Xcode (для симуляторов)

## Установите зависимости:
```

yarn install

```
